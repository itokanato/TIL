# Gitの初期設定について

## 初期設定手順

1. ローカルで作業用フォルダを作成する
2. `git init`を実行する
3. ユーザー情報の設定
   ```bash
   # グローバル設定を行うにはコマンドに`--global`をつける
   git config user.name "USERNAME"
   git config user.email "EMAIL@ADDRESS"
   ```
4. デフォルトブランチの設定
   - 新規リポジトリの場合：
     ```bash
     git config init.defaultBranch main
     ```
   - 既存の「master」を「main」に変更する場合：
     ```bash
     git branch -M main
     ```
5. 最初のコミット
   ```bash
   # ステージング
   git add .
   # コミット
   git commit -m "コミットメッセージ"
   ```
6. リモートリポジトリへの接続
   ```bash
   git remote add origin https://github.com/USERNAME/HOGEHOGE.git
   ```
7. リモートリポジトリへのプッシュ（例：mainブランチ）
   ```bash
   git push -u origin main
   ```

## リポジトリのクローン方法

既にGitHub上に存在するリポジトリをクローンする場合：

```bash
git clone https://github.com/USERNAME/HOGEHOGE.git
```
